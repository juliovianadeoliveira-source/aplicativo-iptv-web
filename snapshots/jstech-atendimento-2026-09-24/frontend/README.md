# JSTech Atendimento

Painel próprio de atendimento com Supabase + GitHub Pages.

## O que já existe
- Login com Supabase Auth
- Dashboard
- Conversas em tempo real
- CRM de clientes
- Bot por fluxo e botões
- Simulador do fluxo
- Base de conhecimento para IA
- Fallback de IA
- Webhook da Meta Cloud API
- Envio manual do atendente
- Configurações de Phone Number ID e WABA ID

## Edge Functions
- jstech-wa-webhook
- jstech-wa-send

## Segredos necessários no Supabase
- META_VERIFY_TOKEN
- META_APP_SECRET
- META_WHATSAPP_TOKEN
- META_GRAPH_VERSION
- OPENAI_API_KEY

As chaves privadas nunca devem ser colocadas neste repositório.
